# VIRASAT — Digital Guardian of Indian Culture

## Overview
VIRASAT bridges physical exhibits and digital cultural stories through QR/NFC-ready discovery. This static, no-build MVP is designed for a reliable Smart India Hackathon demonstration.

## Features
Explore/search/filter 10 heritage records; detailed stories; Leaflet/OpenStreetMap map with offline fallback; QR demo/manual codes/camera request; NFC simulation; artisan profiles; quiz and badges; favourites/recent history; local AI storyteller; Hindi interface basics; dark/accessibility modes and local persistence.

## Run
Open the folder in VS Code and use Live Server, or run `python -m http.server 5500` and open `http://localhost:5500`. Internet improves map tiles and remote imagery, but core interaction remains local.

## SIH flow
Home → Explore → search Chikankari → story → map → Scan → Try Demo Scan → story → Quiz.

## Future scope
Institution dashboard, multilingual AI, computer vision, AR, 3D archives and responsible artisan discovery links.
